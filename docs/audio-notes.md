# 原创声音设计

这支 5 秒样片的所有声音由 `scripts/audio.py` 数学合成，没有使用参考视频的配乐、录音采样或下载素材。声音源代码按本项目 MIT 许可发布；生成的 WAV 同样作为本项目原创产物发布。

运行：

```sh
python3 scripts/audio.py
```

默认输出 `assets/audio/sample.wav`（48 kHz、立体声、PCM16、准确 5 秒）以及同名 JSON 事件表与音量数据。依赖 NumPy；随机种子固定为 `241107`。

## 材料与节奏

- 120 BPM，稀疏的柔和低鼓、轻沙锤与 D 大调五声音阶木琴。
- 小人落地、纸片归拢和盖章用短木质触感；面板展开用柔和空气与玻璃泛音。
- 声像从左向右移动，跟随角色与纸片；所有声音共享一组短房间反射。
- 0.00–0.15 秒保持安静；4.23 秒后没有新事件，让结尾自然衰减。
- 输出样本峰值约 −3.2 dBFS，为 AAC 编码预留余量；末尾 0.28 秒平滑淡出。

## 接触事件

| 时间 / 秒 | 画面 | 声音 |
|---|---|---|
| 0.25 | Pip 落地 | 柔和低鼓＋木质落地 |
| 0.75、1.25、1.75 | 三片想法归拢 | 三个短木触感＋由低到高的轻玻璃泛音 |
| 1.92–2.40 | Inbox 开始展开 | 空气擦动；2.00 秒加入铰链触感 |
| 2.50 | 卡片打开 | 柔和玻璃共鸣 |
| 3.00、3.25、3.50 | 三行计划成形 | 轻木触感与短木琴回应 |
| 4.15 | 角色盖下最后的勾 | 低鼓＋较厚木质接触 |
| 4.17–4.23 | 完成反馈 | 三音玻璃和弦，随后自然衰减 |

`sample.json` 保留每个事件的时间与声像，后续调整画面时应同步修改脚本时间表。
