# 参考视频的重构提示词

> 这是根据用户提供的视频、作者公开案例说明重构的制作提示词，**不是作者原始提示词**。作者没有公开这条片子的 HTML 合成文件、Blender 模型、配乐工程与完整创作对话。本文件用于说明怎样把画面翻译为可执行需求。

参考来源：[onetake / clawd-desktop-19s 制作复盘](https://github.com/feitangyuan/onetake/blob/main/cases/clawd-desktop-19s/README.md)。

## 可复制的重构提示词

```text
制作一支约 19 秒、16:9 的三维桌面动效短片。中心创意是“角色就是鼠标指针”：每次界面变化，都必须由角色可见的身体动作引起。整片在同一个桌面空间中连续完成，通过摄影机的位置、景别和高度变化引导注意力。

场景：把浅色 macOS 风格桌面表现成玻璃桌台，Dock 是一排有厚度的应用图标，终端、浏览器和通知都是空间中的薄玻璃面板。主体是 Claude Code 的 Clawd 吉祥物。先在 Blender 中制作角色，再导出 GLB，交给 three.js 编排场景和动画。

故事：角色落到应用图标上，沿 Dock 奔跑，踩下终端图标。终端窗口弹出，角色沿输入框跳动，输入“make something useless”。程序回复并生成 useless.html。角色举起文件，把它搬到浏览器图标上。浏览器展开，出现“do nothing”按钮。角色跳上按钮，窗口摇头，通知提示“Did nothing.”。角色再逐个最小化窗口，回到起始图标，桌面打出“made with onetake”，最后一次跳跃接回开头。

动作语法：落地代表点击，沿文字行跳动代表输入，举起文件代表拖拽。起跳有预备压缩，空中轻微拉长，落地有挤压和衰减回弹。角色必须跟随其所在图标或窗口上的局部锚点，因此窗口晃动、弹跳、缩小时角色也跟随。

镜头：开场低位斜看 Dock；奔跑时贴着 Dock 跟拍；输入时靠近窗口并抬高到可以读字的角度；整理窗口时升高进入总览；结尾回到起点。用带缓冲的跟随与落地后的短暂稳定，避免从头到尾匀速旋转。

材质：明亮、柔和、浅色背景。窗口有透射与折射，正面叠加可读 UI；图标有圆润厚度、轻微高光与接触阴影。焦点服务于当前动作，远处可轻微虚化，不能让关键词失去可读性。

节奏：按照 126 BPM、约 40 拍组织动作。把落地、弹窗、文件放下等关键接触排在选定拍点，保留输入、左右看和眨眼的停顿。不要把每一拍都填满。

实现：所有位置、旋转、缩放、文字进度、窗口状态和摄影机参数都从绝对时间 t 计算；同一时间应产生同一画面。动画由一个 HTML 合成入口组织。逐帧调用时间定位函数，通过 Chromium 截图，采用时间内多次采样的运动模糊，再用 FFmpeg 编码为 MP4。音效与视觉接触事件共用时间表。

验收：全片动作具有明确因果；角色不丢失；关键文字有停留阅读时间；玻璃与景深不遮蔽信息；运动有快慢与停顿；结尾可以连续接回开头。先检查关键帧和低成本样片，再提高渲染质量。
```

## 哪些内容可以确认

- 作者案例说明确认了：角色充当指针、Blender 制作角色、three.js 桌面场景、绝对时间驱动合成、玻璃窗口、多镜头位置采样景深、快门运动模糊和逐拍分镜。
- “写成上述一段提示词”的表达是本项目重新组织的；不能将其标为作者原文或“一次输入即得到成片”的证据。
- 作者复盘记录了多个概念、配乐筛选和版本修改。成片质量来自创意、代码与反馈迭代的共同作用。

## 与本项目的关系

本项目借鉴的是“角色引起界面反应”“连续空间”“按时间求值”“动作与声音共享事件”的方法。新的 Pip 角色、界面、剧情、代码和声音独立制作。参考片和其品牌素材不包含在本项目发布内容中，也没有复制 onetake 的实现代码。
