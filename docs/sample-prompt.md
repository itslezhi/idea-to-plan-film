# 原创 5 秒样片提示词

工作名：**Idea to Plan / 把想法变成下一步**。画面主标题：**A LITTLE ORDER.**

这份提示词描述当前 5 秒样片的创作目标。当前样片采用程序化 three.js 建模，Pip 由原创几何体构成；不依赖 Blender，也没有使用 Clawd、Apple 图标或参考视频的模型。

## 主提示词

```text
你是一名三维动效导演兼 creative developer。用独立编写的 three.js 制作一支 5.000 秒、1920×1080、30fps、16:9 的原创短片，项目名 idea-to-plan-film。交付浏览器可播放的动画、确定性逐帧渲染脚本、带原创合成声音的 MP4、关键帧、完整源代码及中文说明。先完成这 5 秒样片，完整长片只写方案，等待样片审看后再扩展。

核心创意：一个叫 Pip 的薄荷青色小信使，依次跳上三片零散想法，每次落地把对应卡片送入收件盘，收件盘展开成一张清晰的计划卡。观众应在五秒里读懂“散乱 → 归拢 → 有序”。落地分拣是整片的统一动作语法。

视觉：暖白与浅奶油色背景，一块有柔和高光的桌面；鼠尾草绿、淡紫、杏黄色为辅助色。Pip 是原创圆角方体小信使，有两只小眼睛和短小的脚，轮廓简洁，像可触摸的小玩具。不要使用螃蟹轮廓、Claude 吉祥物、Apple 图标、macOS Dock、品牌标志和参考片文案。UI 是原创的实体卡片和收件盘。

场景布局：前景或中景可清楚看见三片想法卡；杏黄色 Inbox 收件盘位于它们移动的终点；桌面留出足够空白。卡片用小色块或简单线条表达想法，不塞入细密文字。Pip 的起始小平台位于左侧，三片卡从左到右排向收件盘。最终 Plan 卡标题为 ONE CLEAR PLAN，包含 Gather ideas、Choose a direction、Make the first move 三行和一个清楚的完成勾。画面主标题为 A LITTLE ORDER.。

时间轴：120 BPM，每拍 0.5 秒，共 10 拍。
0.0–0.5 秒：Pip 从上方进入，在 0.25 秒落到左侧小平台上，建立行动方向。
0.5–2.0 秒：Pip 依次跳向三片想法，在 0.75、1.25、1.75 秒落下；被踩卡片短促下压后飞向或滑入右侧杏色 Inbox。每次必须先看见落脚，后看见对应卡片出发。
2.0–3.0 秒：Pip 在 2.00 秒到达 Inbox，触发展开；2.50 秒计划卡完整打开。新结构必须从旧对象长出来。
3.0–4.0 秒：三条整齐的计划行在 3.00、3.25、3.50 秒出现；Pip 转身、抬脚，为盖章作准备，镜头上升到可以读懂结果的位置。
4.0–4.5 秒：Pip 在 4.15 秒盖下完成勾；角色、卡片和阴影有短促接触回弹。
4.5–5.0 秒：保留最终构图的阅读时间，只允许很小的衰减余动。

镜头：只有一个连续空间与一个连续摄影机。开场从低位三分之四角度看向卡片，跟随 Pip 的跳跃方向略微移动；收件盘展开时平滑升高并后退，结尾完整看见 Pip 与 Plan 卡。角色是视觉线索，镜头不丢失它。不要硬切、无动机的飞镜头或持续匀速环绕。

运动：起跳前有小幅蓄力，落地时有短促挤压，释放后有衰减回弹。角色动作和 UI 反应必须共享事件时间，不能出现角色没碰到卡片而卡片自己走的情况。每个对象的状态由绝对时间 t 计算；不能依赖运行帧率，不在渲染路径调用随机数。每次定位到同一 t，得到相同画面。

材质与灯光：柔和大面积光源感、圆润边缘、可见接触阴影与轻微反射。桌面或卡片可以有克制的半透明质感，文字与完成勾保持清楚。先保证形体、因果和可读性，再增加材质细节。

声音：原创程序合成，120 BPM；使用柔和敲击、纸片滑动、展开的空气声和完成时的清脆点音。主要声音与接触同步，结尾给结果留一点空间。无需下载商业配乐或引用参考片声音。

工程：用 HTML 作为合成入口，three.js 绘制；提供等待场景就绪与定位时间的接口。使用 Playwright/Chromium 在确定时间采样，按帧编码，FFmpeg 合成声音。npm run dev 打开预览，npm run stills 生成检查帧，npm run render 导出默认 5 秒样片。保留固定版本的依赖锁文件，使新机器可复现。

验收：输出精确 5 秒、30fps 的 150 帧视频；无浏览器错误、丢模型、文字缺字和画面越界；三次想法归拢及最终盖章均能看出接触因果；最终三条计划行可见；结尾至少约半秒读图；声音不削波；源代码和声音为本项目原创并可随 MIT 项目发布，第三方依赖保留其许可证。
```

## 每轮修改只解决一个问题

先检验“看不看得懂”，再检验“动得是否自然”，最后检验“材质与声音是否精致”。可追加这些短指令：

- 因果不清楚：`把每次接触前后各留 2–3 帧辨识时间，增加接触压缩，确保手脚或身体真的接近卡片。`
- 节奏平均：`减少无信息的摆动，将起跳蓄力、快速落地和结果停留区分开，保留最后半秒阅读。`
- 镜头太忙：`减少摄影机位移，角色跳跃时跟随，卡片展开时再抬高，最终稳定。`
- 结果看不清：`把计划卡放大或抬高视角，减少卡片倾斜，保持角色与结果都在画面内。`
- 声音太密：`只保留归拢、展开、盖章的主事件，降低辅助声响，不要每帧或每拍都响。`
