# 分镜与动作时间表

## 5 秒样片：当前制作范围

规格：1920×1080，16:9，30fps，5.000 秒，共 150 帧；120 BPM，每拍 0.5 秒，共 10 拍。画面内只保留必要短词，重点依靠角色与物件的动作讲清楚。

“镜头”在下表指同一连续镜头内的段落，没有场景硬切。表中时间是创作节奏约定，实际接触帧以代码事件表为准；修改视觉动作时需要同步修改对应声音事件。

| 时间 | 拍 | 画面与动作 | 因果与延续 | 摄影机 | 声音 |
|---|---:|---|---|---|---|
| 0.0–0.5s | 0–1 | Pip 从上方入场，0.25s 落到左侧小平台 | 落地建立角色重量与行动方向 | 低位斜看桌面，清楚交代三片卡与盘的位置 | 0.25s 柔和落地，前段留白 |
| 0.5–1.0s | 1–2 | 0.75s 踩中第一片，卡片下压后飞向 Inbox | 脚接触 → 卡片压缩 → 出发 | 沿跳跃方向轻跟随 | 第一次柔和敲击与短滑动 |
| 1.0–1.5s | 2–3 | 1.25s 踩中第二片，第二片跟随归拢 | 第一片仍是连续路线的一部分 | 维持角色与卡片关系 | 第二次敲击，音色稍有变化 |
| 1.5–2.0s | 3–4 | 1.75s 踩中第三片，三片依次进入杏色 Inbox | 第三次落地 → 盘接住最后一片 | 注意力转向收件盘 | 第三次敲击，收件时轻落点 |
| 2.0–2.5s | 4–5 | 2.00s Pip 到达 Inbox，收件盘受压展开 | 角色落到盘上 → 盘展开 | 抬高并略后退，预留展开空间 | 铰链触感与展开气声 |
| 2.5–3.0s | 5–6 | 2.50s Plan 卡完整打开，标题可见 | 同一对象换形态，边界连续 | 平滑过渡到能看清卡面的角度 | 柔和玻璃共鸣后收住 |
| 3.0–3.5s | 6–7 | 三条计划行在 3.00、3.25、3.50s 成形 | 三片对象的数量、颜色与排列保持对应 | 轻微调整构图，结果成为主角 | 三个克制的归位点音 |
| 3.5–4.0s | 7–8 | 最后一行出现后，Pip 转身、抬脚蓄力 | 观众有时间识别“已经整理好” | 减速，准备最终稳定 | 短暂停顿或很轻的准备声 |
| 4.0–4.5s | 8–9 | 4.15s Pip 盖下完成勾，卡片短促回弹；4.30s 开始跳到卡片右侧让开印记 | 落脚 → 勾出现 → 角色让开 | 可有极轻接触响应，不能影响读图 | 一次清脆盖章音，短和弦回应 |
| 4.5–5.0s | 9–10 | 4.50s 让位结束，Pip 与 Plan 卡停留，三条计划和完成勾完整可见 | 保留成果，不再开启新动作 | 稳定构图 | 简短余韵后收尾 |

## 拟议 20 秒完整版：方案，尚未制作

完整版将扩展同一个原创故事，而非把参考视频的终端、Safari 与窗口最小化流程换皮。暂按 120 BPM、40 拍、约 20 秒规划；5 秒样片审看后再确定长度、文案和后半段结构。

叙事句：**Pip 把一桌想法整理成计划，再把计划送进可执行的时间里。**

| 时间 | 叙事任务 | 角色与 UI 动作 | 镜头与衔接 | 待确认内容 |
|---|---|---|---|---|
| 0–2s | 建立问题 | 三片想法散落；Pip 进入并试探其中一片 | 低位桌面建立空间，靠角色动作吸引注意力 | 想法使用图形还是短词 |
| 2–5s | 归拢 | Pip 依次踩中想法卡，把它们送入 Inbox | 沿桌面连续跟随；卡片始终承接前一动作 | 归拢的快慢与每次接触力度 |
| 5–8s | 从收集到结构 | Inbox 展开为 Plan 卡，三条计划依次形成 | 摄影机升高，旧容器成为新卡片 | Plan 卡需要展示的三条内容 |
| 8–10s | 取舍 | Pip 把一个重复小片抽出，另外两行重新排齐 | 镜头靠近操作，保留整张卡的定位线索 | 是否需要这段“取舍”，或更直接地保留三行 |
| 10–13s | 安排执行 | Pip 拉出卡片一角，展开一条原创时间带；计划行滑入三个时段 | 时间带从卡片伸出，摄影机顺势侧移 | 时间带显示日期、时长还是阶段 |
| 13–16s | 展示结果 | 三个任务在时间带上落位；Pip 沿着时段检查 | 从近到远显示完整有序结构，允许短暂停顿 | 这是工具宣传片还是纯概念短片 |
| 16–18s | 完成 | Pip 盖下完成勾，时间带折叠为一张可携带的小计划卡 | 原有对象聚合成最终成果，镜头不跳空间 | 完成标记与卡片造型 |
| 18–20s | 署名与收尾 | Pip 抱起小卡，出现项目标题与简短署名 | 保持结果可读；可设计为自然结束或接回入场 | 用户自己的项目名、GitHub 地址、片尾文字 |

## 检查重点

1. **因果**：先发生角色接触，再发生 UI 响应；不能只靠同时运动来假装接触。
2. **对象延续**：每个段落能指出从上一段保留下来的角色或物件。
3. **可读性**：缩小到常见播放窗口，仍能辨认三片想法、收件盘、三条计划和最终完成勾。
4. **节奏**：落地分拣、展开和盖章是主要事件；过渡与停留也占有时间。
5. **摄影机**：角色和当前操作点始终可见，远处空白不抢画面。
6. **声音**：接触声与接触帧一致；最终勾有明确落点；保留空隙。
7. **范围**：当前样片验收只覆盖 0–5 秒独立小故事；20 秒表格是后续创作方案。
