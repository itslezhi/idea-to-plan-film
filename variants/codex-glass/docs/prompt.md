# Codex Glass · v2 制作提示词

这是根据用户修订要求编写的原创制作提示词，供代码动画工作流使用。参考片作者未公开这条具体成片的 HTML 与模型；以下内容不代表作者原始提示词。

## 主提示词

```text
制作一条 5 秒、1920×1080、30 fps 的高质感三维软件动效样片。

视觉方向：采用参考视频那种可辨认的 Apple/macOS 桌面软件美学。
使用真实、可核实来源的 macOS 应用图标，组成有半透明底座的 Dock；
图标有精致的圆角、细薄厚度、明亮边缘和自然软阴影。
壁纸是柔和的桃色与浅蓝渐变，桌面像一张具有轻微反射的平整屏幕表面。
窗口具有透亮玻璃、细薄高光、乳白界面层和可读的深色等宽文字。
用浅景深、克制的镜头跟随、真实的运动模糊表现体积与速度。
画面的主体是 Dock、角色和窗口；给软件画面留足空间。

角色：将本机 Codex 原生图标的云朵轮廓挤出为有厚度的三维角色。
保留图标本身的蓝紫渐变和白色 >_ 表情，身体边缘做精致倒角与亮面。
加上细小的蓝色手臂和脚，让云朵用身体完成点击与跳跃。
明确称为本项目制作的 Codex 图标动画角色，不称为 OpenAI 官方吉祥物。
它承担鼠标指针的叙事角色：身体落地引发点击，跳跃引发打字，
踩下输入行引发提交。让每次界面反应都能看见身体上的原因。

完整动作表：
0.25 秒：角色落到 Codex Dock 图标，图标压下回弹，周围图标放大形成涟漪。
0.80 秒：落到 Messages 图标。
1.25 秒：落到 Photos 图标。
1.65 秒：落到 Terminal 图标。
1.65–2.05 秒：Terminal 图标带着角色一起弹跳和回落。
2.05–2.65 秒：Codex 终端玻璃窗口从 Terminal 图标位置弹出并展开，
             主玻璃落稳重音在 2.20 秒。
2.80、3.10、3.40 秒：角色沿输入行做三次跳跃，
                    依次形成 make / something / delightful。
完整提示句是：make something delightful。
3.65 秒：角色踩下提交并短促压缩，光标切换为加载指示。
3.65–3.90 秒：短暂加载；3.90 秒开始回复。
4.20–5.00 秒：窗口保持 Ready to build.，角色留在窗口附近，
             保留稳定阅读时间和自然呼吸。

镜头：全片一镜连续，先低位贴着 Dock 向右追随角色；
窗口弹出时抬升并靠近输入行；最后轻微拉回，角色与回复共同留在画面内。
让摄影机有克制的跟随滞后和落稳，快速移动后有短暂阅读停顿。
角色、图标、窗口和摄影机保持同一三维空间关系。

程序：使用 Three.js。所有动画参数都是绝对时间 t 的确定函数。
暴露 window.__ready、window.__seek(t)、window.__meta 和检查接口。
界面文字可用高分辨率 Canvas 纹理，玻璃使用透射材质；
角色站立点绑定到图标或窗口的局部坐标，避免物体移动时脚底打滑。
用浏览器逐帧渲染，多时间采样在线性光空间合成快门运动模糊，
再用 FFmpeg 合入原始合成音轨，导出 H.264/AAC MP4。

声音：126 BPM、细致克制的原创电子打击底层律动。
落地、图标回弹、2.20 秒玻璃展开、三次打字接触和 3.65 秒提交是主要重音。
声像随角色从左向右移动；4.20 秒后只保留余音。
不用参考片 BGM。音轨为 5 秒、48 kHz 立体声，峰值预留约 3 dB 余量。

交付：5 秒 MP4、联系表、可运行源代码、实际动作/声音时间表和依赖说明。
保留已有 v1，新的视觉与声音作为 codex-glass 变体。
```

## 逐步执行提示词

1. **场景与角色**：先完成壁纸、Dock、真实应用图标，以及由原生 Codex 云朵图标挤出的蓝紫色角色；保留白色 `>_` 表情和细小蓝色四肢。输出低位 Dock 近景和玻璃窗口近景，检查图标识别、角色质感、玻璃透亮度。
2. **身体触发**：按分镜建立四次 Dock 落地与 Terminal 回弹；角色与受力物体绑定同一接触时间。先保证空间和动作因果关系，再加入细微表情。
3. **窗口与输入**：让窗口从 Terminal 图标真实位置展开；三次跳跃同步输入三个词；提交后显示加载和 `Ready to build.`，保留结尾阅读时间。
4. **摄影与材质**：完成低位跟随、向窗口抬升和结尾轻拉回；分别调整背景失焦、角色清晰度、玻璃透射与文字对比。
5. **声音与输出**：运行变体声音脚本；核对全部接触点，再渲染带多采样运动模糊的 1080p30 MP4。检查首尾状态、角色完整入镜、重复 seek 的确定性、资源加载和无削波音轨。

## 实际命令

从仓库根目录执行 `npm run dev`，打开 [Codex Glass 本地预览](http://127.0.0.1:4173/variants/codex-glass/)。运行 `npm run stills:codex` 输出分镜帧，`npm run check:codex` 检查资源、关键位置与确定性，`npm run render:codex` 输出 5 秒 MP4。变体产物统一写入 `variants/codex-glass/output/`。

参考方法来源：[onetake 的 Clawd desktop 案例复盘](https://github.com/feitangyuan/onetake/tree/main/cases/clawd-desktop-19s)。本变体的代码、动画、附加肢体与声音由本项目制作；Codex 原生图案与 macOS 图标保留各自品牌归属。
