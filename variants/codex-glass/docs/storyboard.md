# Codex Glass · v2 · 5 秒分镜

这次修订保留参考片可辨认的 Apple/macOS 软件质感：真实应用图标、Dock 放大反馈、透亮玻璃窗口、桃色与浅蓝壁纸、浅景深和贴着角色移动的连续镜头。角色从本机 Codex 原生图标的云朵轮廓挤出，形成有厚度的蓝紫色三维云朵，保留白色 `>_` 表情，并加上细小的蓝色手臂和脚。这是本项目制作的 Codex 图标动画角色，不是 OpenAI 发布的官方吉祥物。

本样片只完成一条清楚的操作链：**沿 Dock 跳跃 → 启动终端 → 输入提示 → 出现回复**。5 秒用于验证视觉、角色和动作质感；参考片中生成文件、拖进浏览器和窗口总览等后续情节留给长片。

| 时间 | 动作与界面 | 镜头与阅读重点 | 声音接触点 |
|---|---|---|---|
| 0.00–0.25 | 蓝紫色 Codex 云朵从画面上方落向 Codex 图标；Dock 邻近图标随距离放大 | 低位斜侧近景，清楚看见图标厚度、亮边与桌面壁纸 | 0.25 秒，柔和身体落地＋轻玻璃反馈 |

| 0.80–1.25 | 云朵角色跳到 Photos 图标 | 保持同一空间和运动方向，Photos 花瓣图标可辨认 | 1.25 秒，短接触 |
| 1.25–1.65 | 跳到 Terminal 图标，身体轻微压扁回弹 | 黑色 Terminal 图标提供清楚的视觉落点 | 1.65 秒，较厚接触 |

## 实现约束

- 输出 1920×1080、30 fps、5 秒；成片使用逐帧渲染和多时间采样运动模糊。
- 全片用同一个三维桌面和连续摄影机承接动作；窗口从实际 Dock 图标位置生长。
- 角色落地、图标压缩、Dock 放大、窗口展开和文字出现共用绝对时间事件表。
- 角色站在图标或窗口上时使用局部锚点，让图标弹跳和窗口回弹自然带动角色。
- 关键文字保持清楚：输入句和回复各有阅读时段，透射层不能把字洗白；失焦主要落在背景与远处图标。
- 图标采用本机 macOS 应用图像；Codex 角色基础轮廓与正面图案来自原生应用图标。立体挤出造型、附加肢体和动画由本项目制作；品牌图像保留原归属。
- 保留 v1；v2 位于 `variants/codex-glass/`。

## 声音文件

运行 `python3 variants/codex-glass/scripts/audio.py`，生成本变体的 `assets/audio/sample.wav` 和同名事件 JSON。音轨为 48 kHz 立体声、准确 5 秒，原始合成峰值约 −3.2 dBFS，固定随机种子 `261107`。126 BPM 的轻电子律动只作底层节奏，表中的身体接触点优先。没有使用参考片的 BGM、录音采样或外部曲库。

## 预览、检查与渲染

从仓库根目录运行：

```sh
npm run dev
npm run stills:codex
npm run check:codex
npm run render:codex
```

预览地址：[Codex Glass 本地预览](http://127.0.0.1:4173/variants/codex-glass/)。检查报告写入 `variants/codex-glass/output/check.json`；成片写入 `variants/codex-glass/output/codex-glass-5s.mp4`。构图检查覆盖落地和跳跃顶点的 18 个时间点，并检查 `4.8 → 1.25 → 4.8` 重复定位的截图确定性。


## 拟议 20 秒完整版（待样片方向反馈后扩展）

| 时间 | 动作与结果 |
| --- | --- |
| 0–5s | 本次样片：Codex 沿 Dock 启动终端，输入并提交提示 |
| 5–8s | 终端生成 `playground.html`；角色从输出行带出立体文件 |
| 8–11s | 角色将文件送到 Safari，玻璃浏览器从图标中展开 |
| 11–14s | 浏览器里出现一个可交互的微型星球游乐场；角色拨动其中一颗小球 |
| 14–17s | 星球运行起来，代码窗口与运行结果保持同框，角色拖动窗口让出主体 |
| 17–20s | 镜头升高作窗口总览，再回到 Dock；用 Codex 与项目 GitHub 地址收尾 |

完整版的输出是可玩的微型世界，与参考片的“无用按钮”故事区分；继续保留真实软件界面和身体触发操作的表达。
